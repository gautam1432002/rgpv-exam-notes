1.1 Basics of Computer Vision and Image Processing (CVIP)
5 Marks7 Marks10 Marks
Definition

Image Processing is a method of performing operations on a digital image to improve its quality or extract useful information from it. It involves processing an image using mathematical operations to produce a better image or to extract features.

Computer Vision (CV) is a field of Artificial Intelligence that enables computers to interpret and understand the visual world — just like human eyes and brain. It goes beyond image processing by adding intelligence and decision-making.

Simple Analogy: Image Processing = Making a photo look better (like Instagram filters). Computer Vision = Teaching a computer to recognize what is IN the photo (like face recognition on your smartphone).

What is a Digital Image?

A digital image is a 2D array (matrix) of numbers. Each element of this matrix is called a pixel (picture element). For a grayscale image, each pixel has a value from 0 (black) to 255 (white). For a color image, each pixel has 3 values — Red, Green, Blue (RGB).

Types of Digital Images
  • Binary Image: Each pixel is either 0 (black) or 1 (white). Used in morphological processing. Size: 1 bit per pixel.
  • Grayscale Image: Pixel values 0–255. 8 bits (1 byte) per pixel. Used in medical imaging, feature detection.
  • Color Image (RGB): 3 channels — Red, Green, Blue. 24 bits per pixel. Used in photography, video.
  • Multispectral Image: More than 3 channels. Used in satellite imagery and remote sensing.
  • Hyperspectral Image: Hundreds of channels. Used in agriculture and mineralogy.
Applications of CVIP
  • Medical: MRI/CT scan analysis, tumor detection, X-ray diagnosis
  • Security: Face recognition, fingerprint matching, iris scanning
  • Industrial: Quality control, defect detection, OCR (barcode reading)

  • Agriculture: Crop disease detection, yield estimation using drone images
  • Entertainment: AR/VR, movie special effects, video game graphics
  • Robotics: Robot navigation, object grasping, scene understanding

1.3 Computer Vision (CV) Models
5 Marks7 Marks
Introduction

A Computer Vision Model is a framework or computational approach that defines how an image is processed and interpreted to extract meaningful information. Different models look at the problem of understanding images from different angles.

Major CV Models

1. Marr's Three-Level Model (1982) — Most Important!

David Marr proposed that vision operates at three levels of abstraction:
  • Computational Level: WHAT is computed and WHY? (Goal of vision — e.g., "detect edges")
  • Algorithmic Level: HOW is it computed? (Which algorithm — e.g., "Canny edge detection")
  • Implementation Level: WHERE is it computed? (Hardware — e.g., "GPU running C++ code")
Marr's Three-Level Vision Model
Level 1: PRIMAL SKETCH
Edges, bars, blobs, boundaries from raw image
⬇
Level 2: 2.5D SKETCH
Depth, orientation, visible surfaces — viewer-centered
⬇
Level 3: 3D MODEL
Object-centered 3D representation — shape, volume

2. Geometric Model:

  • Represents objects as geometric primitives — lines, circles, polygons, polyhedra.
  • Uses shape parameters for recognition. Example: Detecting circular objects using Hough Circle Transform.

3. Probabilistic/Statistical Model:

  • Uses probability distributions to model appearance of objects.
  • Example: Bayesian classifiers, Gaussian Mixture Models (GMM) for object segmentation.

4. Deep Learning Model (Modern):

  • Convolutional Neural Networks (CNN) automatically learn features from data.
  • No hand-crafted features needed. End-to-end learning from raw pixels.
  • Example: ResNet, VGG, YOLO for object detection and classification.
⭐

Marr's Three-Level Model is the most important CV model for RGPV exams. Remember: Computational (WHAT+WHY) → Algorithmic (HOW) → Implementation (WHERE). Marr's three stages: Primal Sketch → 2.5D Sketch → 3D Model.

Definition

Image Filtering is a technique used to modify or enhance an image by applying a mathematical operation (called a filter or kernel/mask) to each pixel and its neighborhood. It is used for noise removal, sharpening, blurring, edge detection, etc.

How Filtering Works: A small matrix called a kernel (or mask) is slid over the image. At each position, the kernel values are multiplied by the underlying pixel values and summed up to produce the output pixel value. This process is called convolution.

Types of Image Filters

1. Low-Pass Filters (Smoothing / Blurring):

  • Mean Filter (Average Filter): Replaces each pixel with the average of its neighborhood. Removes noise but blurs edges.
  • Gaussian Filter: Weighted average — center pixel gets more weight. Better than mean filter, used in Gaussian blur. Kernel: Bell-shaped curve.
  • Median Filter: Replaces pixel with the median of neighborhood values. Very effective for salt-and-pepper noise removal without blurring edges.

2. High-Pass Filters (Sharpening / Edge Detection):

  • Laplacian Filter: Computes second derivative — detects edges and fine details. Makes image look sharper.
  • Sobel Filter: Computes gradient in X and Y directions — detects edges with direction information.
  • Prewitt Filter: Similar to Sobel but uses equal weights. Simpler edge detection.
  • Unsharp Masking: Enhances edges by subtracting blurred version from original image.
Sobel Kernels: Gx = [-1 0 +1] Gy = [-1 -2 -1] [-2 0 +2] [ 0 0 0] [-1 0 +1] [+1 +2 +1] Edge magnitude: G = √(Gx² + Gy²) Edge direction: θ = arctan(Gy/Gx)

3. Frequency Domain Filters:

  • Images are converted to frequency domain using Fourier Transform (FFT).
  • Low-Pass Filter (LPF): Keeps low frequencies (smoothing), removes high frequencies (edges, noise).
  • High-Pass Filter (HPF): Keeps high frequencies (edges), removes low frequencies (smooth regions).
  • Band-Pass Filter: Keeps frequencies in a specific range.
Advantages
  • Removes noise and improves image quality.
  • Enhances specific features (edges, textures).
  • Prepares image for further processing (segmentation, recognition).
⭐

Convolution = sliding a kernel over image and computing weighted sum. Low-pass = blurring/smoothing, High-pass = sharpening/edge detection. Median filter = best for salt-and-pepper noise. Sobel filter detects edges with direction. Remember Sobel kernel values (1,2,1 pattern).

1.5 Image Representations and Image Statistics
5 Marks7 Marks
Image Representations

An image can be represented in different ways depending on the processing task. The choice of representation affects what operations can be efficiently performed.

  • Spatial Domain Representation: Direct 2D matrix of pixel intensities f(x,y). Most common. Operations applied directly to pixels.
  • Frequency Domain Representation: Image expressed as sum of sinusoidal waves using Fourier Transform F(u,v). Useful for filtering and compression.
  • Pyramid Representation: Multiple resolution versions of the same image — Gaussian pyramid (blurred), Laplacian pyramid (edges). Used for multi-scale analysis.
  • Graph Representation: Image as a graph where pixels = nodes, edges = similarity between adjacent pixels. Used in graph-cut segmentation.
  • Run-Length Encoding (RLE): Compact representation for binary images — encode consecutive pixels of same value. e.g., "5W 3B 4W" = 5 white, 3 black, 4 white pixels.
  • Chain Code Representation: Boundary of a region encoded as sequence of 8-directional moves. Compact boundary description.
Image Statistics

Image statistics provide numerical descriptions of pixel distribution in an image. These are used for quality assessment, feature extraction, and thresholding.

Step-wise Explanation

1. Conditioning: The first step — pre-processing the image to improve its quality and make subsequent steps easier.

  • Noise removal (Gaussian, Median filtering)
  • Contrast enhancement (Histogram equalization)
  • Geometric correction (removing distortion)
  • Illumination normalization (removing uneven lighting)
  • Goal: Get a clean, well-prepared image for analysis.

2. Labeling: Assigning meaningful labels to pixels or regions based on their properties.

  • Thresholding: Label pixels as foreground (1) or background (0) based on intensity.
  • Edge labeling: Mark pixels as edge or non-edge.
  • Region labeling: Connected component labeling — assign unique ID to each connected region.

3. Grouping: Combining labeled pixels/features into meaningful structures — regions, edges, curves.

  • Region growing: Group similar adjacent pixels into regions.
  • Edge linking: Connect detected edge points into continuous edges/lines.
  • Clustering: Group similar pixels using k-means or other algorithms.

4. Extracting: Computing descriptors/features from grouped regions or edges that describe their properties.

  • Region features: Area, perimeter, centroid, bounding box, moments.
  • Shape features: Circularity, elongation, compactness, Hu moments.
  • Texture features: GLCM (Gray Level Co-occurrence Matrix), LBP.
  • Boundary features: Chain code, Fourier descriptors.

5. Matching: Comparing extracted features with stored models or templates to identify/recognize the object.

  • Template matching: Compare region with stored template images.
  • Feature matching: Compare feature vectors using distance measures (Euclidean, Mahalanobis).
  • Structural matching: Compare structural relationships between parts.
  • Decision: Best match above threshold = recognized object.
⭐

The 5-step recognition pipeline is very commonly asked. Remember: Conditioning (clean image) → Labeling (mark pixels) → Grouping (form regions) → Extracting (compute features) → Matching (compare with model). This is the foundation of ALL computer vision systems.

✏️ The recognition methodology provides a systematic, structured approach to object recognition. Each step builds upon the previous one, transforming a raw noisy image into a recognized, labeled object.

Introduction to Mathematical Morphology

Mathematical Morphology is a theory and technique for analyzing and processing geometric structures in images. It is based on set theory, lattice theory, and topology. Originally developed by Matheron and Serra (1964) at École des Mines de Paris.

Key Idea: Morphological operations use a Structuring Element (SE) — a small shape/template — that is probed against the image to modify it. The SE determines what structures are preserved, removed, or altered.

Dilation is a morphological operation that expands/grows the bright regions (white pixels) in a binary image. It adds pixels to the boundary of objects.

Rule: If the SE origin is placed at pixel (x,y) and AT LEAST ONE pixel of the SE overlaps a foreground (1) pixel in the input image, then the output pixel at (x,y) = 1.

EROSION (⊖)

Erosion is a morphological operation that shrinks/erodes the bright regions (white pixels) in a binary image. It removes pixels from the boundary of objects.

Rule: Output pixel at (x,y) = 1 ONLY IF ALL pixels of the SE overlap foreground (1) pixels when the SE is placed at (x,y). Otherwise output = 0.
Effect: Removes small protrusions and isolated pixels, separates touching objects, shrinks objects.
Dilation: A ⊕ B = { z | (B̂)z ∩ A ≠ ∅ } Erosion: A ⊖ B = { z | Bz ⊆ A } Where: A = input image (set), B = structuring element, Bz = B translated by z

1.8 Morphological Operations: Opening, Closing, Hit-or-Miss Transform
5 Marks7 Marks10 Marks
Opening (∘)

Opening is defined as Erosion followed by Dilation using the same structuring element.

Opening: A ∘ B = (A ⊖ B) ⊕ B Step 1: Erode A with B → removes small protrusions and thin connections Step 2: Dilate result with B → restores approximate original size of remaining objects
Effect: Removes small objects/protrusions smaller than SE while preserving shape of larger objects. Smooths object contours. Separates narrow connections (isthmuses) between objects.
Application: Removing thin noise, separating touching objects, smoothing boundaries.
Closing (•)

Closing is defined as Dilation followed by Erosion using the same structuring element.

Closing: A • B = (A ⊕ B) ⊖ B Step 1: Dilate A with B → fills small holes and gaps Step 2: Erode result with B → restores approximate original boundary
Effect: Fills small holes and gaps inside objects, closes narrow breaks in boundaries, smooths contours by joining nearby objects.
Application: Filling holes in segmented objects, closing small gaps in boundaries.

Properties of Opening and Closing
  • Opening is Anti-extensive: A ∘ B ⊆ A (result is always a subset of original)
  • Closing is Extensive: A ⊆ A • B (result always contains original)
  • Both are Idempotent: Applying twice gives same result as once: (A ∘ B) ∘ B = A ∘ B
  • Duality: Opening and closing are duals: (A • B)ᶜ = Aᶜ ∘ B̂
Hit-or-Miss Transform (⊛)

The Hit-or-Miss Transform is used for detecting specific patterns or shapes in a binary image. It uses TWO structuring elements simultaneously.

Hit-or-Miss: A ⊛ (B1,B2) = (A ⊖ B1) ∩ (Aᶜ ⊖ B2) Where: - B1 = Foreground structuring element (must HIT inside object) - B2 = Background structuring element (must MISS outside object) - Aᶜ = Complement of A - A pixel is detected only if B1 fits inside the object AND B2 fits outside
Application: Finding specific pixel configurations — isolated pixels, line ends, corners, bridges between objects. It is the basis for thinning and thickening algorithms.
⭐

Opening = Erosion THEN Dilation → removes small protrusions. Closing = Dilation THEN Erosion → fills small holes. Easy memory trick: "Opening OPENS up narrow isthmuses (removes)", "Closing CLOSES gaps (fills)". Hit-or-Miss uses 2 SEs — B1 (foreground) and B2 (background) — detects specific shapes.

1.9 Morphological Algorithms: Binary & Gray-Scale, Thinning, Thickening, Region Growing & Shrinking
5 Marks7 Marks10 Marks
Morphological Operations on Gray-Scale Images

While basic morphology works on binary images, it can be extended to gray-scale images using the following definitions:

Gray-scale Dilation: (f ⊕ b)(x,y) = max{f(x-s, y-t) + b(s,t)} for (s,t) in SE domain Gray-scale Erosion: (f ⊖ b)(x,y) = min{f(x+s, y+t) - b(s,t)} for (s,t) in SE domain Where f = input gray image, b = gray-scale structuring element
  • Gray Dilation: Replaces each pixel with the LOCAL MAXIMUM in the SE neighborhood → brightens image, expands bright regions.
  • Gray Erosion: Replaces each pixel with the LOCAL MINIMUM in the SE neighborhood → darkens image, expands dark regions.
  • Gray Opening: Removes bright peaks (highlights) smaller than SE. Smooths image from above.
  • Gray Closing: Removes dark valleys (shadows) smaller than SE. Smooths image from below.
  • Morphological Gradient: (f⊕b) − (f⊖b) → highlights edges of gray-scale objects.
  • Top-Hat Transform: f − (f∘b) → extracts small bright objects on dark background.
  • Black-Hat Transform: (f•b) − f → extracts small dark objects on bright background.
Thinning

Thinning is a morphological operation that reduces binary objects to their skeleton — a 1-pixel-wide representation preserving topology and connectivity.

How Thinning Works:
Iteratively apply Hit-or-Miss transform with a set of 8 structuring element pairs (representing different boundary configurations). Remove pixels that satisfy the transform while preserving connectivity. Repeat until no more pixels can be removed (stable skeleton).

Region Shrinking is the inverse of region growing — it reduces a region by removing boundary pixels that do not meet the homogeneity criterion. Used to refine over-segmented regions.

2.1 Image Representation Schemes
5 Marks7 Marks
Introduction

After segmenting an image into regions, we need to represent and describe these regions for further processing. Representation deals with HOW we store/encode the region; Description deals with WHAT features we extract.

Representation Schemes

1. Boundary (External) Representation: Describes only the outer boundary/contour of a region.

  • Chain Code: Encodes boundary as sequence of directional moves. 4-directional (right=0, up=1, left=2, down=3) or 8-directional (0-7). Compact, translation invariant. Start from a fixed point and trace boundary.
  • Polygonal Approximation: Approximate the boundary with a polygon of fewer vertices. Reduces data while preserving shape.
  • Signatures: 1D function representing boundary — e.g., distance r(θ) from centroid at angle θ. Converts 2D boundary to 1D signal.
  • Boundary Segments: Decompose boundary into meaningful segments (lines, curves, corners).

2. Region (Internal) Representation: Describes the interior content of a region.

  • Skeleton: Medial Axis Transform — thin skeleton of the region. Preserves topology.
  • Quad-tree: Hierarchical region decomposition — recursively divide into 4 quadrants until each quadrant is homogeneous.
  • Run-Length Encoding: Encode each row as runs of same pixel values. Efficient for simple shapes.
  • Pyramids: Multi-resolution representation — Gaussian and Laplacian pyramids.

2.2 Boundary Descriptors and Region Descriptors
5 Marks7 Marks
Boundary Descriptors

Boundary Descriptors describe properties of the boundary (contour) of a segmented region. They are used for shape recognition and matching.

  • Perimeter: Length of the boundary. Count of boundary pixels (or more accurately, sum of distances between consecutive chain code points).
  • Diameter: Longest chord in the boundary — maximum distance between any two boundary points.
  • Eccentricity: Ratio of diameter to the perpendicular width. Measures elongation.
  • Curvature: Rate of change of tangent angle along the boundary. High curvature = corners, low = smooth curves.
  • Fourier Descriptors: DFT of complex boundary representation z(s) = x(s)+jy(s). Lower-frequency coefficients capture coarse shape; higher-frequency = fine details. Scale, rotation, translation invariant (with normalization).
  • Shape Numbers: First difference of chain code normalized to smallest integer (see Unit 3).
Region Descriptors

Region Descriptors describe properties of the interior area of a region. They are computed from all pixels inside the region.

  • Area: Number of pixels in the region. Simple and fundamental descriptor.
  • Centroid (Center of Mass): Average x and y coordinates of all pixels. x̄ = (1/A)Σx, ȳ = (1/A)Σy
  • Bounding Box: Smallest rectangle enclosing the region. Defined by min/max x and y coordinates.
  • Compactness (Circularity): Perimeter² / (4π × Area). Circle = 1 (most compact), elongated shapes > 1.
  • Aspect Ratio: Width / Height of bounding box. Discriminates tall vs. wide objects.
  • Moments: Statistical moments of pixel distribution — used to compute centroid, orientation, skewness (see Unit 3 for detailed moments).
  • Mean Intensity: Average gray level inside the region. (1/A) Σ f(x,y)
  • Variance/Texture: Spread of intensities inside region — measures texture.

2.3 Binary Machine Vision: Thresholding and Segmentation
5 Marks7 Marks10 Marks
Binary Machine Vision

Binary Machine Vision deals with processing binary (black and white) images to extract information about the shape and location of objects. It is used in industrial inspection, robotics, and document analysis.

Thresholding

Thresholding is the simplest image segmentation technique. It converts a grayscale image to binary by comparing each pixel to a threshold value T.

Binary Thresholding: g(x,y) = { 1 (White/Foreground) if f(x,y) ≥ T { 0 (Black/Background) if f(x,y) < T Where f(x,y) = input pixel, T = threshold, g(x,y) = output binary pixel
Types of Thresholding
  • Global Thresholding: Single threshold T applied to entire image. Works when illumination is uniform. Otsu's Method automatically finds optimal T by maximizing between-class variance.
  • Local/Adaptive Thresholding: Different threshold for different image regions. Good for non-uniform illumination. T(x,y) = mean of neighborhood ± constant.
  • Multi-level Thresholding: Multiple thresholds T1, T2, ... classify pixels into multiple regions.
  • Optimal Thresholding (Otsu's Method): Finds threshold that minimizes intra-class variance (maximizes inter-class variance) by analyzing histogram. Most commonly used automatic method.

Types of Segmentation

1. Connected Component Labeling:

After thresholding, assigns a unique label to each connected group of pixels (connected component = a group of pixels connected to each other).

  • 4-connectivity: Pixel connected to its 4 neighbors (up, down, left, right).
  • 8-connectivity: Pixel connected to all 8 neighbors (including diagonals).
  • Algorithm: Two-pass algorithm — first pass assigns temporary labels, second pass resolves equivalences using union-find.
  • Application: Counting objects (cells, coins), character segmentation in OCR.

2. Hierarchical Segmentation:

  • Creates a hierarchy of nested regions from fine to coarse (dendrogram).
  • Bottom-up: Start with pixels as individual regions, merge similar adjacent regions iteratively.
  • Top-down: Start with entire image, recursively split based on homogeneity criterion.

3. Spatial Clustering:

  • K-means Clustering: Divide pixels into K clusters based on intensity/color similarity. Iteratively update cluster centers until convergence.
  • Mean-Shift: Find modes (density peaks) in feature space. Non-parametric, no need to specify K.
  • DBSCAN: Density-based clustering — finds arbitrarily shaped clusters.

4. Split and Merge:

  • Split phase: Start with whole image, recursively split into 4 quadrants if region is not homogeneous.
  • Merge phase: Merge adjacent similar regions that together satisfy homogeneity criterion.
  • Uses quad-tree structure. Homogeneity: variance of intensity < threshold.

5. Rule-Based Segmentation:

  • Uses domain knowledge as rules to guide segmentation.
  • Example: "If pixel intensity > 200 AND in top-half of image → sky region".
  • Used in document analysis, medical imaging with known anatomy.

6. Motion-Based Segmentation:

  • Segments moving objects from static background in video sequences.
  • Background Subtraction: Subtract current frame from background model → moving objects appear as foreground.
  • Optical Flow: Compute pixel motion between frames using Lucas-Kanade or Horn-Schunck method → segment regions with similar motion.
  • Application: Surveillance cameras, traffic monitoring, action recognition.

2.4 Area Extraction: Edge Detection, Hough Transform, Line & Curve Fitting
5 Marks7 Marks10 Marks
Edge Detection

Edge detection identifies boundaries between regions of different intensity in an image. Edges correspond to significant local intensity changes and represent object boundaries.

Edge Detection Methods
  • First Derivative Operators (Gradient): Roberts, Sobel, Prewitt — compute gradient magnitude. Strong gradient = edge. Simple but sensitive to noise.
  • Second Derivative (Laplacian): Find zero-crossings of second derivative. Laplacian of Gaussian (LoG/Marr-Hildreth) — smooth then find zero-crossings.
  • Canny Edge Detector (Best!): Optimal edge detector. Steps: (1) Gaussian smoothing, (2) Gradient computation, (3) Non-maximum suppression, (4) Double thresholding, (5) Edge tracking by hysteresis. Produces thin, connected edges.
Line Linking

Line linking connects detected edge pixels into continuous lines or curves. Local methods: link pixels with similar gradient magnitude and direction within a neighborhood. Global methods: Hough Transform.

Hough Transform

The Hough Transform is a feature extraction technique that can detect parametric shapes (lines, circles, ellipses) in images even when the shapes are partially occluded or noisy.

Key Idea: Each edge point in image space votes for all possible lines/curves that pass through it. The shape that collects the most votes in parameter space is the detected shape.

3.1 Region Analysis: Region Properties and External Points
5 Marks7 Marks
Region Properties

Region properties are quantitative measurements computed from a segmented region that capture its geometric, photometric, and topological characteristics for recognition and classification.

Geometric Properties
  • Area (A): Total number of pixels in the region. Fundamental size measure.
  • Perimeter (P): Length of boundary. For binary image: count boundary pixels.
  • Centroid (x̄,ȳ): Center of mass of the region. x̄=m₁₀/m₀₀, ȳ=m₀₁/m₀₀.
  • Bounding Box: Smallest axis-aligned rectangle enclosing the region.
  • Orientation: Angle of major axis with x-axis. Computed from second-order moments.
  • Major/Minor Axes: Lengths of principal axes of equivalent ellipse.
  • Aspect Ratio: Major axis / Minor axis. Circularity ≠ 1 implies elongation.
  • Compactness/Circularity: P² / (4π × A). Circle = 1, elongated shapes > 1.
Topological Properties
  • Euler Number (E): E = C − H, where C = number of connected components, H = number of holes. A solid disk: E=1. A letter O: E=0. A letter B: E=-1.
  • Genus: Number of handles on an object (topological concept).
  • Connectivity: Whether the region is simply connected (no holes) or multiply connected (with holes).
External Points (Extreme Points)

External points (also called extreme points) are the topmost, bottommost, leftmost, and rightmost points of a region boundary. They give a compact description of region extent.

  • Top point: Boundary pixel with minimum y-coordinate (highest in image).
  • Bottom point: Boundary pixel with maximum y-coordinate.
  • Left point: Boundary pixel with minimum x-coordinate.
  • Right point: Boundary pixel with maximum x-coordinate.
  • Convex Hull: Smallest convex set containing all region pixels. External points help define it.
  • Application: Quick bounding box computation, object pose estimation, feature-based matching.
⭐

Region properties: Area, Perimeter, Centroid, Compactness, Euler Number. Euler Number = Components − Holes. Compactness = P²/(4πA) = 1 for circle. External points = top, bottom, left, right extremes of boundary. These form basic features for object classification.

3.2 Spatial Moments and Mixed Spatial Gray-Level Moments
5 Marks7 Marks10 Marks
Introduction to Moments

Moments are weighted averages of pixel intensities that capture the shape and distribution of an image region. They are used as compact shape descriptors for object recognition.

Spatial (Geometric) Moments
General Moment of Order (p+q): m_pq = Σ_x Σ_y x^p · y^q · f(x,y) Where: p,q = orders, f(x,y) = pixel intensity at (x,y) Zeroth-order moment (m₀₀): m₀₀ = Σ_x Σ_y f(x,y) = Total intensity (or area for binary image) First-order moments: m₁₀ = Σ_x Σ_y x·f(x,y) (related to x-centroid) m₀₁ = Σ_x Σ_y y·f(x,y) (related to y-centroid) Centroid: x̄ = m₁₀/m₀₀, ȳ = m₀₁/m₀₀
Central Moments (Translation Invariant)
Central Moment (translation invariant): μ_pq = Σ_x Σ_y (x-x̄)^p · (y-ȳ)^q · f(x,y) Second-order central moments: μ₂₀ = Σ(x-x̄)²·f(x,y) ← x-axis variance (inertia) μ₀₂ = Σ(y-ȳ)²·f(x,y) ← y-axis variance μ₁₁ = Σ(x-x̄)(y-ȳ)·f(x,y) ← covariance Orientation of major axis: θ = 0.5 · arctan(2μ₁₁ / (μ₂₀ - μ₀₂))
Normalized (Scale Invariant) Moments
Normalized central moment (scale invariant): η_pq = μ_pq / μ₀₀^γ Where γ = (p+q)/2 + 1
Hu Moments (Rotation, Scale, Translation Invariant)

Hu (1962) derived 7 invariant moments from normalized central moments that are invariant to rotation, scaling, and translation:

Hu Moment Invariants (φ₁ to φ₇): φ₁ = η₂₀ + η₀₂ (sum of second-order) φ₂ = (η₂₀ - η₀₂)² + 4η₁₁² (difference) φ₃ = (η₃₀ - 3η₁₂)² + (3η₂₁ - η₀₃)² φ₄ = (η₃₀ + η₁₂)² + (η₂₁ + η₀₃)² φ₅ = ... (higher order) φ₆ = ... φ₇ = ... (skew-sensitive) Hu moments are invariant to: Rotation, Scale, Translation (RST)
Mixed Spatial Gray-Level Moments

Mixed spatial gray-level moments combine spatial position information with gray-level intensity information.

Mixed Moment: m_pq = Σ_x Σ_y x^p · y^q · g(x,y)^r Where g(x,y) = gray-level intensity, r = gray-level order Example (p=1, q=0, r=1): m₁₀ = Σ_x Σ_y x · g(x,y) ← first x-moment weighted by intensity These capture joint distribution of spatial position and intensity → useful for texture characterization and distinguishing regions with same shape but different intensity distributions.
⭐

Moment order (p+q): m₀₀ = area/total intensity, m₁₀,m₀₁ = related to centroid, μ₂₀,μ₀₂,μ₁₁ = orientation. Hu's 7 moments are RST invariant (Rotation, Scale, Translation). Central moments = translation invariant. Mixed moments include both spatial AND gray-level information. Hu moments most important for recognition!

3.3 Boundary Analysis: Signature Properties and Shape Numbers
5 Marks7 Marks
Signature (Boundary Signature)

A signature is a 1D representation of a 2D boundary obtained by plotting some boundary property as a function of a parameter (usually angle or arc length). It converts the 2D shape analysis problem into a 1D signal analysis problem.

Types of Signatures
  • Distance Signature r(θ): Distance from centroid to boundary point at angle θ.
    r(θ) = √[(x(θ)-x̄)² + (y(θ)-ȳ)²] Circle: r(θ) = constant Ellipse: r(θ) = varies sinusoidally
  • Tangent Angle Signature φ(s): Angle of boundary tangent at arc length position s. Cumulative version is called the turning function.
  • Complex Coordinate Signature z(s) = x(s) + jy(s): Complex representation of boundary points parameterized by arc length. Its DFT gives Fourier descriptors.
  • Curvature Signature κ(s): Curvature of boundary as function of arc length. Peaks at corners.
Signature Properties
  • Periodicity: Signature repeats after one full traversal of the boundary (period = boundary length or 2π).
  • Translation Invariance: Moving the shape doesn't change the signature (centroid-based signatures).
  • Rotation Effect: Rotation shifts the signature horizontally. Normalize by starting from a canonical point.
  • Scale Effect: Scaling changes amplitude. Normalize by average radius.
  • Noise Sensitivity: Small boundary perturbations cause small signature changes (continuity).
  • Fourier Analysis: DFT of signature gives frequency components. Low frequencies = coarse shape, high frequencies = fine details.
Shape Numbers

Shape number is a compact descriptor derived from the chain code of the boundary. It is invariant to the starting point of the chain code traversal.

Chain Code → First Difference → Shape Number: Step 1: Compute chain code of boundary Example chain code: 0 1 1 2 3 3 0 (for some shape) Step 2: First difference (subtract consecutive elements, mod 8): If chain code = [c₀, c₁, c₂, ..., cₙ₋₁] First difference: dᵢ = (cᵢ - cᵢ₋₁) mod 8 Step 3: Shape number = smallest integer from all rotations of the first difference sequence (this makes it starting-point independent) Shape number order = number of elements in the sequence (= perimeter in grid steps)
  • Shape numbers represent the "shape" of an object boundary independent of starting position, scale, or rotation.
  • Simpler shapes have small shape numbers; complex shapes have longer sequences.
  • Example: A square has shape number of order 4 (4 turns of 90° each).
  • Used for simple shape classification and database retrieval.
⭐

Signature = 1D representation of 2D boundary. Most common: r(θ) = distance from centroid to boundary. Shape number = first difference of chain code → find minimum rotation (shape number = smallest integer). Shape number is invariant to starting point of traversal. For exam: show the derivation process step by step.

1. Distance Relational Approach

Measures similarity between two structures using a distance metric in feature space. The object model with minimum distance is the match.

  • Euclidean Distance: d = √Σ(fᵢ-mᵢ)² between feature vector f and model m.
  • Mahalanobis Distance: D² = (f-m)ᵀ Σ⁻¹ (f-m). Accounts for feature correlations and scales.
  • Hamming Distance: Number of positions where binary strings differ. Used for binary feature vectors.
  • Hausdorff Distance: Maximum of minimum distances between two point sets. Used for shape matching.
  • Decision: Match if distance < threshold θ. Nearest-neighbor or k-NN classification.
2. Ordered Structural Matching

Matches objects by comparing their structural relationships between parts in an ordered manner.

  • Object described as a set of primitives (parts) with relationships (above, left-of, connects-to).
  • Match is successful if the structural graph of observed object is isomorphic (or similar) to the model graph.
  • String Matching: Represent boundary as a string of symbols → match using string edit distance (Levenshtein distance).
  • Graph Matching: Model as attributed relational graph → find graph isomorphism.
  • Tree Matching: Hierarchical structure of object → match subtrees recursively.
  • Application: OCR (character matching by stroke structure), circuit board inspection.
3. View Class Matching

3D objects appear differently from different viewpoints. View class matching handles this by organizing models into groups of similar views (view classes).

  • A view class is a set of viewpoints from which the object looks topologically similar (same silhouette topology).
  • The complete set of view classes for an object = aspect graph — a graph where nodes = view classes, edges = visual transitions.
  • Recognition steps:
    1. Extract 2D features from observed image.
    2. Determine which view class the observation belongs to.
    3. Match against models for that view class.
    4. Verify with geometric consistency.
  • Application: 3D object recognition from 2D images, model-based vision in robotics.
4. Models Database Organization

Efficient organization of the model database is critical for fast matching when there are thousands of objects.

  • Linear Search: Compare against every model. O(n) — slow for large databases.
  • Tree Structures: KD-tree, Ball tree for feature vectors. O(log n) nearest-neighbor search.
  • Hash Tables: Geometric hashing — store model features in hash table, query at recognition time.
  • Inverted Index: Used in large-scale image retrieval (like VLAD, Fisher vectors + FAISS).
  • Clustering: Group similar models — only search most similar cluster during recognition.
  • Indexing by View: Organize by pose/aspect for view-based matching systems.
⭐

4 matching frameworks: Distance relational (Euclidean/Mahalanobis/Hausdorff distance), Ordered structural (graph/string matching), View class (aspect graph, viewpoint groups), Models database (KD-tree, hashing). Hausdorff distance = useful for shape matching. Geometric hashing = fast model retrieval.

✏️ Matching is the bridge between extracted features and object identity. Different frameworks suit different problems — distance-based for simple features, structural for complex object parts, view-class for 3D objects, and efficient databases for large-scale systems.

4.1 Facet Model Recognition: Labeling Lines & Understanding Line Drawings

Introduction — Facet Model

The Facet Model treats an image as a collection of flat surfaces (facets). It models the image intensity function as piecewise polynomial patches and uses this to detect edges and interpret 3D structure. Proposed by Haralick et al.

Line Labeling in 3D Interpretation

In line labeling, every edge in a line drawing of a 3D polyhedron is assigned a label indicating its physical interpretation in 3D space. This was pioneered by Huffman and Clowes (1971).

Types of Line Labels
  • Convex Edge (+): The edge where two visible surfaces meet at a convex angle (fold toward viewer). Drawn as solid line with "+" label.
  • Concave Edge (−): The edge where two surfaces meet at a concave angle (fold away from viewer). Drawn as solid line with "−" label.
  • Boundary Edge (→): An occluding contour where one surface is visible and the other is hidden. Arrow points so that the visible surface is on the right.

Understanding Line Drawings (Waltz Algorithm)

Understanding line drawings means interpreting a 2D line drawing as a 3D object. Waltz's Algorithm (1972) uses constraint propagation to find globally consistent labelings.

  • At each junction (where lines meet), only certain label combinations are physically possible (junction dictionary).
  • Types of junctions: Y-junction (3 lines at ~120°), Arrow-junction (like ≺), T-junction (1 line meets another), L-junction (2 lines).
  • Start with all possible labels for each line, propagate constraints through junctions to eliminate impossible combinations.
  • If globally consistent labeling exists → valid 3D interpretation. If no consistent labeling → impossible figure.
Classification of Shapes by Labeling Edges

By analyzing the junction labels and edge labels, we can classify the type of 3D object depicted:

  • Convex polyhedron: All edges labeled (+) or boundary (→).
  • Concave object / hole: Contains (−) labeled edges.
  • Shadow edges: Special labels for illumination effects.
  • Impossible figures: No globally consistent labeling exists (like Penrose triangle).
Consistent Labeling Problem

The consistent labeling problem asks: Given constraints between labels at junctions, find an assignment of labels to all lines that satisfies all constraints simultaneously.

  • This is a form of Constraint Satisfaction Problem (CSP).
  • Number of possible labelings can be exponential in the number of lines.
  • Efficient solution using arc consistency and constraint propagation reduces search space dramatically.

4.2 Perspective Projective Geometry & Inverse Perspective Projection
5 Marks7 Marks10 Marks
Perspective Projection

Perspective Projection is the mathematical model describing how 3D world points are mapped to 2D image points through a camera lens. It models how real cameras form images.

Pinhole Camera Model: Light from world point P(X,Y,Z) passes through the camera center (pinhole) and creates image point p(x,y) on the image plane at distance f (focal length).
Perspective Projection Equations: Camera at origin, image plane at z = f (focal length): x = f · X/Z (horizontal projection) y = f · Y/Z (vertical projection) In homogeneous coordinates: [sx] [f 0 0 0] [X] [sy] = [0 f 0 0] [Y] [s ] [0 0 1 0] [Z] [1] Where s = Z (depth), actual image point: (x,y) = (sx/s, sy/s)
Camera Model Components
  • Focal Length (f): Distance from camera center to image plane. Larger f = more zoom, narrower field of view.
  • Principal Point (cx, cy): Intersection of optical axis with image plane (usually image center).
  • Intrinsic Matrix (K): Camera calibration matrix containing f, cx, cy, and skew.
  • Extrinsic Parameters [R|t]: Rotation and translation from world to camera coordinates.
  • Projection Matrix P = K[R|t]: Full 3×4 matrix mapping 3D → 2D.
Full Camera Model: Image point x = K · [R | t] · X_world Where K = [[fx s cx] (Intrinsic - camera properties) [ 0 fy cy] [ 0 0 1]] R = Rotation matrix, t = Translation vector (Extrinsic - camera pose)
Effects of Perspective Projection
  • Foreshortening: Objects appear smaller as they move farther away (1/Z effect).
  • Parallel lines converge: In 3D, parallel lines appear to meet at a vanishing point in 2D image.
  • Depth information lost: Many 3D points map to the same 2D point (along a ray through camera center).
Inverse Perspective Projection (Back-Projection)

Inverse Perspective Projection is the process of recovering 3D world information from 2D image measurements. It is the core problem of 3D reconstruction.

Inverse Problem (given image point (x,y), find 3D point): From x = f·X/Z and y = f·Y/Z: X = x·Z/f (need Z to find X) Y = y·Z/f (need Z to find Y) Problem: Z (depth) is unknown from a single image! → Need additional information to recover Z: - Second camera (stereo vision) - Known object size - Structured light projection - Depth sensor (LiDAR, ToF camera)
⭐

Perspective projection: x = f·X/Z, y = f·Y/Z. Key effects: smaller farther (1/Z), parallel lines converge, depth lost. Intrinsic matrix K contains f, cx, cy. Inverse projection needs depth Z — requires stereo or depth sensor. Homogeneous coordinates make projection linear (matrix multiplication).

4.4 Image Matching: Intensity Matching, 2D Matching, Hierarchical Matching
5 Marks7 Marks10 Marks
Introduction to Image Matching

Image matching is the process of finding corresponding locations between two or more images of the same scene. It is fundamental to stereo vision, optical flow, panorama stitching, and change detection.

1. Intensity Matching of 1D Signals

Before 2D image matching, the principles are understood through 1D signal matching. Given two 1D signals f(x) and g(x), find the displacement d that makes them best aligned.

Cross-correlation for 1D matching: CC(d) = Σ_x f(x) · g(x + d) Peak of CC(d) → best displacement d Normalized Cross-Correlation (NCC): NCC(d) = CC(d) / √[Σf(x)² · Σg(x+d)²] Range: -1 to +1, 1 = perfect match
2. Matching of 2D Images (Template Matching)

Template matching finds a small reference image (template T) within a larger image (source S) by sliding the template over the image and computing similarity at each position.

Sum of Squared Differences (SSD): SSD(x,y) = Σ_u Σ_v [S(x+u, y+v) - T(u,v)]² → minimum SSD = best match location Sum of Absolute Differences (SAD): SAD(x,y) = Σ_u Σ_v |S(x+u, y+v) - T(u,v)| Normalized Cross-Correlation (NCC): NCC(x,y) = Σ[S(x+u,y+v)·T(u,v)] / √[Σ S² · Σ T²] Range: -1 to 1, best match at maximum NCC
  • Advantages: Simple, works well for rigid templates with consistent appearance.
  • Disadvantages: Slow (O(MN·WH) where MN=image size, WH=template size), sensitive to scale/rotation changes, needs exact template.
  • Speed-up: Use FFT for correlation (O(MN log MN)), or image pyramids for coarse-to-fine search.
Feature-Based 2D Matching
  • Detect distinctive keypoints in both images (SIFT, SURF, ORB, Harris corners).
  • Compute descriptors for each keypoint (128-dim SIFT vector).
  • Match descriptors using nearest-neighbor distance (Euclidean or Hamming).
  • Filter outliers using RANSAC with geometric model (homography, fundamental matrix).
3. Hierarchical Image Matching

Hierarchical matching uses an image pyramid to do coarse-to-fine matching. It reduces computation and avoids local minima in the search.

Hierarchical (Coarse-to-Fine) Matching

  • Advantages: Reduces search space dramatically (from global to local at each level). Avoids local minima. Much faster than full-resolution search (O(N²) → O(N)). Handles large displacements.

4.5 Object Models and Matching: 2D Representation, Global vs Local Features
5 Marks7 Marks
2D Object Representation Models

Before matching, objects must be represented in a model database. 2D representation models describe objects as they appear in images.

  • Template Model: Store object appearance as a gray-level image patch. Simple but requires exact appearance match. Used in template matching.
  • Contour/Boundary Model: Represent object by its outer boundary (chain code, Fourier descriptors, B-spline). Efficient, view-independent shape matching.
  • Part-based Model: Describe object as collection of parts with spatial relationships. Example: Pictorial Structures, Deformable Part Model (DPM).
  • Feature Point Model: Represent as set of keypoints with descriptors (SIFT, SURF). Invariant to scale, rotation, partial occlusion.
  • Statistical Model: Point Distribution Model (PDM) — mean shape + variations (PCA on landmark points). Active Shape Models, Active Appearance Models.

5.1 Knowledge-Based Vision: Knowledge Representation, Control Strategies, Information Integration
5 Marks7 Marks10 Marks
Introduction to Knowledge-Based Vision

Knowledge-Based Vision (KBV) systems use domain-specific knowledge explicitly represented in the system to guide image interpretation. Instead of purely data-driven processing, KBV combines image data with prior knowledge about the domain (anatomy, object structure, scene context).

Why Knowledge is Needed: Image data alone is often ambiguous — the same image region can be interpreted multiple ways. Domain knowledge resolves ambiguity. Example: In medical imaging, knowing that "this bright circular structure near the spine is likely a kidney" helps correctly segment the image.
1. Knowledge Representation

Knowledge can be represented in various forms in a KBV system:

  • Rule-Based (Production Rules): IF condition THEN action/conclusion. Example: "IF (region is round AND diameter < 5mm AND near blood vessel) THEN (classify as lymph node)". Simple, interpretable, easy to update. Used in expert systems.
  • Frames / Schema: Organized knowledge structures with slots and fillers. Example: A "Car" frame has slots: wheels=4, has_engine=true, body_shape=[sedan|SUV...]. Default values fill missing information.
  • Semantic Networks: Graph where nodes = concepts, edges = relationships. Example: "wheel IS-PART-OF car", "car IS-A vehicle".
  • Ontologies: Formal, hierarchical organization of domain concepts. OWL, RDF used in semantic web and medical imaging (SNOMED, RadLex).
  • Model-Based: CAD models or geometric descriptions of expected objects. Used in industrial inspection — compare observed with stored 3D model.
  • Probabilistic / Bayesian Networks: Represent uncertain knowledge as probability distributions. P(object | features, context).
2. Control Strategies

Control strategies determine how knowledge and image data are combined and in what order processing steps are executed.

  • Bottom-Up (Data-Driven): Processing starts from raw pixel data and works upward toward high-level interpretation. Good for unexpected objects. Example: Edge detection → region grouping → object hypothesis.
  • Top-Down (Model-Driven): High-level hypotheses about objects expected in the scene guide low-level processing. "If a car is expected, look for wheels and windows." Good for expected objects.
  • Mixed/Bidirectional: Combines both. Bottom-up generates hypotheses, top-down verifies them. Most practical systems use this approach.
  • Blackboard Architecture: All processing modules share a common data structure (blackboard). Each module reads from and writes to the blackboard when it can contribute. A control module decides which module to activate next. Example: HEARSAY-II speech understanding system.
  • Focus of Attention: Apply knowledge to focus processing resources on the most informative image regions, ignoring background.

3. Information Integration

Information integration combines evidence from multiple sources (sensors, image channels, knowledge sources) to reach a more robust interpretation.

  • Multi-sensor Fusion: Combine RGB image + depth (LiDAR) + thermal camera for complete scene understanding.
  • Multi-scale Integration: Combine features from different resolution levels of image pyramid.
  • Temporal Integration: Integrate information across video frames for motion understanding.
  • Bayesian Integration: P(interpretation | all_evidence) ∝ ∏ P(evidence_i | interpretation) × P(interpretation). Combine multiple weak classifiers into strong decision.
  • Context Integration: Use scene context to improve individual object recognition — "objects in a kitchen are likely kitchen appliances".
  • Late Fusion: Each sensor/classifier makes its own decision, then results are combined (voting, averaging).
  • Early Fusion: Raw data from multiple sources combined at pixel level before processing.

Blackboard = shared data structure. Information integration = combine RGB + Depth + context. Bayesian integration is most rigorous.

5.2 Object Recognition using Hough Transforms & Simple Methods
5 Marks7 Marks
Introduction

Object recognition is the task of identifying objects in images — determining what is in the image and where it is located.

Hough Transform for Object Recognition

The Hough Transform can be generalized to recognize arbitrary shapes (not just lines and circles) using the Generalized Hough Transform (GHT).

Generalized Hough Transform (GHT) for Arbitrary Shapes: 1. Training phase: - Choose reference point (centroid) of template shape - For each boundary point, store: (angle θ, displacement r, gradient direction φ) in R-table 2. Recognition phase: - For each edge pixel in input image: - Look up R-table entry for gradient direction φ - Vote for all possible reference point locations (x + r·cos(θ), y + r·sin(θ)) - Peak in accumulator = object location GHT can also accumulate for scale and rotation → finds object at any size/orientation
Simple Object Recognition Methods
  • Template Matching: Slide template over image, find location with maximum NCC. Simple but scale/rotation dependent.
  • Geometric Hashing: Hash model features indexed by geometric invariants. Fast look-up during recognition. Handles partial occlusion.
  • Eigenobjects (Eigenfaces): PCA on object appearances. Project test image to eigenspace, find nearest model. (See Topic 5.4)
  • Bag of Visual Words (BoVW): Cluster local features into visual words. Represent image as histogram of visual word frequencies. Match histograms using χ² distance or cosine similarity.
  • Voting-Based Recognition: Each matched feature votes for possible object identity and location. Object with most votes wins (similar to Hough transform principle).
⭐

Generalized Hough Transform (GHT) = recognize any shape. Training: build R-table of (angle, displacement) for each boundary point. Recognition: vote in accumulator. GHT handles scale and rotation. Bag of Visual Words = powerful for whole-image recognition.

5.3 Shape Correspondence and Shape Matching
5 Marks7 Marks
Shape Correspondence

Shape correspondence is the problem of finding semantic or geometric correspondences between parts of two shapes. It answers: "Which point on shape A corresponds to which point on shape B?"

  • Point-based correspondence: Match corresponding landmark points on two shapes. Used in deformable shape analysis (face, hand).
  • Curve correspondence: Match entire curves or contour segments between two boundary representations.
  • Dense correspondence: For every point on shape A, find the corresponding point on shape B. Used in optical flow and non-rigid registration.
Shape Matching Methods
  • Chamfer Matching: Compute distance transform of edge image; sum distances of template edge points. Efficient and robust to missing parts.
  • Hausdorff Distance: Max of min distances between two shape boundary point sets. d_H(A,B) = max(max_a∈A min_b∈B d(a,b), max_b∈B min_a∈A d(a,b)). Measures worst-case discrepancy.
  • Shape Context: For each boundary point, compute histogram of relative positions of all other boundary points in log-polar space → compact shape descriptor. Match by minimizing total cost of matching all shape context descriptors (Hungarian algorithm).
  • Thin Plate Spline (TPS): Non-rigid transformation that minimizes bending energy while fitting corresponding landmarks. Used for flexible shape alignment.
  • Procrustes Analysis: Rigid alignment of point sets — optimal rotation, scale, translation between two sets of corresponding landmarks. Used in statistical shape models.
  • Earth Mover's Distance (EMD): Minimum "work" needed to transform one distribution into another. Used for shape histogram comparison.
⭐

Shape matching: Hausdorff distance (max of min distances), Chamfer matching (uses distance transform), Shape context (log-polar histogram at each point). Shape correspondence = finding which points match between two shapes. Procrustes analysis = rigid alignment. Thin Plate Spline = non-rigid alignment.

5.4 Principal Component Analysis (PCA) for Computer Vision
5 Marks7 Marks10 Marks
Introduction to PCA

Principal Component Analysis (PCA) is a statistical technique that reduces the dimensionality of data while preserving maximum variance. In image processing, it is used for compact image representation, feature extraction, and face recognition (Eigenfaces).

Intuition: If you have 100 face images of size 100×100 = 10,000 pixels each, PCA finds the few "principal directions" in this high-dimensional space that capture most of the variation. You can represent each face with just 20-50 numbers instead of 10,000 — without losing much information.
PCA Algorithm Step-by-Step
PCA Algorithm: 1. Organize data: N images as column vectors x₁, x₂, ..., xₙ (each of dimension d) Form matrix X = [x₁, x₂, ..., xₙ] (d × N matrix) 2. Compute mean: μ = (1/N) Σᵢ xᵢ 3. Center data: x̃ᵢ = xᵢ - μ → Form X̃ 4. Compute covariance matrix: C = (1/N) X̃ X̃ᵀ (d × d matrix) 5. Eigen decomposition: C vₖ = λₖ vₖ λ₁ ≥ λ₂ ≥ ... ≥ λd (eigenvalues, sorted descending) v₁, v₂, ..., vd (corresponding eigenvectors = Principal Components) 6. Select k largest eigenvalues → keep top-k eigenvectors W = [v₁, v₂, ..., vₖ] 7. Project data: yᵢ = Wᵀ (xᵢ - μ) → k-dimensional representation 8. Reconstruct: x̂ᵢ = W yᵢ + μ (approximate reconstruction)

The Eigenfaces method (Turk & Pentland, 1991) applies PCA to face images for recognition:

Advantages of PCA
  • Reduces data dimensionality — fewer features for faster matching.
  • Removes correlated features — principal components are orthogonal.
  • Optimal linear dimensionality reduction (maximum variance preserved).
  • Noise reduction — small eigenvalues correspond to noise.
Disadvantages of PCA
  • Linear only — cannot capture nonlinear variations (Kernel PCA needed).
  • Sensitive to outliers — outlier images affect covariance matrix.
  • Requires all data at once — not incremental.
  • Not discriminative — maximizes variance, not class separation (LDA is better for classification).
Applications of PCA in CVIP
  • Face recognition: Eigenfaces — compact representation of faces in eigenspace.
  • Image compression: Store only top-k eigenvalues/vectors, reconstruct approximately.
  • Object recognition: Eigenobjects — appearance-based models.
  • Dimensionality reduction for feature vectors: Reduce 1000-dim SIFT bag-of-words to 50-dim for fast matching.
  • Anomaly detection: Images far from principal subspace = anomalous/unusual.
  • Statistical shape models: PCA on landmark positions → Point Distribution Model for shape analysis.
⭐

PCA steps: Compute mean → subtract mean → covariance matrix → eigen decomposition → select top-k eigenvectors → project. Eigenfaces = PCA applied to face images. Each face = linear combination of eigenfaces. Recognition = nearest neighbor in eigenspace. PCA preserves maximum variance with minimum dimensions.

5.5 Feature Extraction for Image Shape Recognition
5 Marks7 Marks
Introduction

Feature extraction transforms raw image data into a compact set of meaningful numerical values (feature vector) that describe the image content for recognition tasks. Good features should be discriminative (different for different classes), invariant (same for same object despite transformations), and compact.

Feature Extraction Techniques

1. Hand-crafted Features (Classical):

  • SIFT (Scale-Invariant Feature Transform): Detects keypoints, computes 128-dim gradient histogram descriptor. Invariant to scale, rotation, illumination. Gold standard for feature matching.
  • HOG (Histogram of Oriented Gradients): Divides image into cells, computes gradient orientation histogram in each cell. Invariant to illumination. Used in pedestrian detection (Dalal & Triggs, 2005).
  • LBP (Local Binary Pattern): Encodes local texture by comparing each pixel to its 8 neighbors. Binary code → histogram. Fast, rotation invariant. Used for face texture and material recognition.
  • Haar Features: Rectangle-based features computing intensity differences in adjacent regions. Used in Viola-Jones face detector.
  • Gabor Features: Responses to oriented, frequency-specific Gabor filters. Captures local texture at multiple scales and orientations.
  • Zernike Moments: Moments based on orthogonal Zernike polynomials. Rotation invariant, used for shape description.

2. Learned Features (Deep Learning):

  • CNN Features: Deep Convolutional Neural Networks automatically learn hierarchical features from data. Early layers = edges, middle = textures, deep layers = object parts, semantic features.
  • Transfer Learning: Use features from pre-trained CNN (VGG, ResNet) as feature extractor for new tasks.
  • Autoencoders: Unsupervised learning of compact latent features by encoder-decoder network.

5.6 Neural Networks and Machine Learning for Image Shape Recognition
7 Marks10 Marks
Introduction

Machine Learning (ML) and Neural Networks (NN) have revolutionized image shape recognition. Instead of hand-crafting features and rules, ML systems learn the recognition function automatically from labeled training data.

Classical Machine Learning Classifiers
  • k-Nearest Neighbors (k-NN): Classify test image by majority vote of k nearest training examples in feature space. Simple, no training phase, but slow at test time.
  • Support Vector Machine (SVM): Finds maximum-margin hyperplane separating classes in feature space. Kernel trick allows nonlinear boundaries (RBF, polynomial kernels). Excellent for high-dimensional features (HOG+SVM for pedestrian detection).
  • Random Forest: Ensemble of decision trees. Each tree trained on random subset of data and features. Majority vote for classification. Fast, handles many features, resistant to overfitting.
  • Naive Bayes: Probabilistic classifier assuming feature independence. P(class|features) ∝ P(features|class) × P(class). Fast and simple.
  • Boosting (AdaBoost): Combine many weak classifiers into strong one. Used in Viola-Jones face detector with Haar features.
