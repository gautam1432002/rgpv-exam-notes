Q1. Discuss the history and evolution of Computer Vision and Image Processing (CVIP). How have advancements in technology influenced its development? 🔥 POPULAR
7 Marks10 Marks
Definition

Computer Vision and Image Processing (CVIP) is a field of Artificial Intelligence that enables computers to interpret, understand, and analyze visual information from the real world — such as images and videos — in the way that humans do.

Difference to remember: Image Processing = transforming an image (enhance, filter, compress). Computer Vision = understanding the image content (detect objects, recognize faces, interpret scenes).
History and Evolution of CVIP
EraKey Development
1960s — DawnLarry Roberts (MIT, 1963) — first CV dissertation on 3D solid objects from 2D images. CVIP began as an academic research area.
1970s — FoundationsDavid Marr proposed the computational theory of vision (3-level model). Edge detection algorithms (Roberts, Prewitt, Sobel) developed.
1980s — GrowthMarr's book "Vision" (1982) formalized CVIP. Hough Transform, texture analysis, stereo vision research flourished.
1990s — MaturityStatistical methods, wavelets, Active Contours (Snakes), face detection (Eigenfaces by Turk & Pentland, 1991). First real-time applications.
2000s — Digital EraSIFT (Scale-Invariant Feature Transform) by Lowe (2004). HOG (Histogram of Oriented Gradients). Medical imaging, surveillance applications.
2010s — Deep Learning RevolutionAlexNet (2012) won ImageNet challenge using CNN — revolutionized CV. Deep Learning replaced hand-crafted features. YOLO, VGG, ResNet, GAN developed.
2020s — PresentVision Transformers (ViT), multimodal AI (CLIP, DALL-E), real-time autonomous driving (Tesla), AR/VR. AI-powered cameras everywhere.
How Technology Influenced CVIP
  • Hardware (GPU): NVIDIA GPUs enabled parallel processing of millions of image pixels — made deep learning feasible.
  • Big Data: ImageNet (14 million labeled images) provided massive training datasets for deep learning models.
  • Internet: Massive image databases available for training (Instagram, Google Images).
  • Embedded Systems: Powerful microprocessors (Raspberry Pi, NVIDIA Jetson) enabled real-time CV on edge devices.
  • Medical Imaging: MRI, CT scan advancements pushed CVIP for automated disease diagnosis.
  • Smartphones: High-resolution cameras + powerful mobile CPUs enabled face unlock, AR filters.
⭐

History table is the most effective way to answer this. Key milestones: 1963 (Roberts), 1982 (Marr's Vision), 1991 (Eigenfaces), 2004 (SIFT), 2012 (AlexNet). Remember: Technology influence = GPU + Big Data + Deep Learning = CVIP revolution.

✏️ CVIP has evolved from simple edge detection algorithms to deep learning-based systems capable of superhuman image recognition — driven by advances in hardware, data availability, and neural network architectures.

Digital Image — Definition

A Digital Image is a 2D matrix of picture elements (pixels), where each pixel has a discrete intensity value representing brightness or color. It is a finite, discrete representation of a continuous analog image.

Image f(x,y) = 2D array of pixels f(x,y) = intensity at position (x, y) x = row (0 to M-1), y = column (0 to N-1) Grayscale: f(x,y) ∈ [0, 255] (0=Black, 255=White) Color: f(x,y) = (R, G, B) triplet

Step 1 — Sampling

Sampling is the process of converting a continuous spatial image into a discrete spatial grid by measuring the image value at regular intervals.

  • The image is divided into a grid of M × N sample points (pixels).
  • Higher sampling rate → more pixels → higher spatial resolution → sharper image.
  • Nyquist Theorem: Sampling frequency must be ≥ 2× the highest spatial frequency in the image to avoid aliasing.
  • Example: 640×480 image = 640 samples in x-direction, 480 in y-direction.
Step 2 — Quantization

Quantization is the process of converting the continuous intensity (amplitude) values at each sample point into discrete integer levels.

  • The continuous range of intensities is divided into 2k discrete levels.
  • k = number of bits per pixel. k=8 → 256 gray levels (0–255).
  • Higher k → more gray levels → smoother image → larger file size.
  • k=1 → Binary image (only Black/White). k=8 → 8-bit grayscale. k=24 → True color (8 bits per R,G,B).
  • Quantization error: The difference between true continuous value and the assigned discrete level — causes "false contouring" if too few levels used.
Elements of a Digital Image Processing System
  • Image Acquisition: Camera, scanner, MRI, CT — captures the image. Converts optical signal to digital data.
  • Image Storage: Primary memory (RAM — for processing), secondary storage (HDD/SSD/Cloud — for archiving).
  • Image Processing Hardware: GPU/FPGA for parallel image processing. DSP chips for real-time processing.
  • Display System: Monitor, printer — outputs the processed image to the user.
  • Image Processing Software: MATLAB Image Processing Toolbox, OpenCV, Photoshop, Python PIL.
  • Networking: For transmitting images (telemedicine, satellite imagery, video surveillance).
  • Hard Copy Devices: Laser/inkjet printers for permanent hardcopy output of processed images.
⭐

Sampling = spatial discretization (how many pixels). Quantization = intensity discretization (how many gray levels). Key formula: Image size = M × N × k bits. Draw the digitization flow diagram. This is asked almost every year!

✏️ Digitization converts the continuous real-world scene into a discrete matrix of pixels through two steps — sampling (spatial) and quantization (intensity) — enabling computers to store, process, and analyze visual information.

Q3. Describe various Computer Vision Models and their applications. What are the different types of CV models? 🔥 POPULAR
— OR —
Q3B. Describe the concept of computer vision. Does it require image processing? Discuss various color vision models. Discuss the procedure for conversion from RGB to HSI color model.
7 Marks10 Marks
Computer Vision — Definition

Computer Vision (CV) is a field of AI that trains computers to interpret and understand visual data from the world — images, videos, 3D scans — and make decisions based on that visual understanding.

Relationship: CV requires image processing as a prerequisite — image processing enhances and prepares images, while CV extracts meaning. Image Processing = Input preprocessing; Computer Vision = Output understanding.
Computer Vision Models
  • 1. Marr's 3-Level Computational Model (1982) ⭐ Most Important:
    • Primal Sketch: Edges, bars, boundaries — raw 2D features from intensity changes.
    • 2.5D Sketch: Depth and surface orientation of objects relative to viewer.
    • 3D Model: Complete 3D representation — object-centered, viewpoint-independent description.
  • 2. Bottom-Up (Data-Driven) Model: Processing starts from raw pixels → features → object recognition. No prior knowledge used. Example: Edge detection → contour grouping → object.
  • 3. Top-Down (Model-Driven) Model: Prior knowledge / model of expected object guides processing. Verify hypotheses against image data. Example: Face detection using known face template.
  • 4. Geometric Model: Uses 3D geometry (camera calibration, perspective projection) to reconstruct 3D world from 2D images. Applications: Robotics, autonomous vehicles.
  • 5. Probabilistic/Statistical Model: Uses statistical methods (Bayesian inference, Hidden Markov Models) to handle uncertainty. Used in gesture recognition, action recognition.
  • 6. Deep Learning Model (CNN): Convolutional Neural Networks learn features automatically from data. State-of-the-art for image classification, object detection (YOLO, Faster R-CNN).
Color Vision Models
  • RGB Model: Additive color model — Red, Green, Blue. Used in monitors, cameras. Each channel: 0-255. Total colors: 256³ = 16.7 million.
  • CMY/CMYK Model: Subtractive model — Cyan, Magenta, Yellow, Black. Used in printing. CMY = complement of RGB.
  • HSI/HSV Model: Hue (color type), Saturation (color purity), Intensity/Value (brightness). Most natural for human perception. Best for image segmentation tasks.
  • YCbCr Model: Separates luminance (Y) from chrominance (Cb, Cr). Used in JPEG compression, TV broadcast.
RGB to HSI Conversion
Given: R, G, B values (normalized 0 to 1) I = (R + G + B) / 3 S = 1 - [3/(R+G+B)] × min(R, G, B) H = arccos{ [(R-G) + (R-B)] / [2√((R-G)²+(R-B)(G-B))] } If B > G: H = 360 - H H ∈ [0°, 360°], S ∈ [0,1], I ∈ [0,1]
Why HSI? In RGB, changing brightness changes all 3 values. In HSI, only I (Intensity) changes — H and S remain same. This makes color-based image segmentation much easier in HSI space.
⭐

Marr's 3-level model is most important — Primal Sketch → 2.5D Sketch → 3D Model. RGB→HSI conversion formula is a direct exam question. Color models: RGB (monitors), HSI (image processing preferred), CMYK (printing). Always write an application for each model.

✏️ Computer vision models provide the theoretical and computational framework for understanding visual information. From Marr's classic 3-level model to modern deep learning CNNs, each model reflects advances in our understanding of both vision and computation.

Image Filtering — Introduction

Image Filtering is the process of modifying pixel values of an image based on the values of neighboring pixels to achieve effects like noise removal, sharpening, or edge detection.

A. Spatial Domain Filtering

Filtering is performed directly on the image pixels using a mask/kernel (small matrix). Result pixel = weighted sum of neighboring pixels.

Output g(x,y) = ΣΣ f(x+s, y+t) × w(s,t) where w(s,t) = filter kernel/mask f = input image, g = output image
  • Mean Filter (Averaging Filter): Replaces each pixel with the average of its neighbors. Blurs the image, removes noise. Kernel: all 1/(k²) values.
  • Median Filter: Replaces pixel with median value of neighbors. Excellent for removing Salt-and-Pepper noise while preserving edges. Non-linear filter.
  • Gaussian Filter: Weighted average — center pixel has highest weight, decreasing towards edges. Smooth blur. Used for noise reduction before edge detection.
  • Sharpening Filter (Laplacian): Enhances edges and fine details. Uses second derivative of image. Kernel: [0,-1,0;-1,5,-1;0,-1,0].
  • Sobel Filter: First derivative filter for edge detection. Separate Gx (horizontal) and Gy (vertical) kernels detect gradient magnitude.
  • High-Pass Filter: Passes high frequencies (edges, details), suppresses low frequencies (smooth regions).
  • Low-Pass Filter: Passes low frequencies (smooth regions), suppresses high frequencies (edges, noise).
B. Frequency Domain Filtering

Image is first transformed to frequency domain using Fourier Transform (FFT). Filtering applied to frequency spectrum, then converted back.

Steps: 1. Compute DFT: F(u,v) = FFT of f(x,y) 2. Apply filter: G(u,v) = H(u,v) × F(u,v) 3. Compute Inverse DFT: g(x,y) = IFFT of G(u,v) Low frequencies = smooth regions (center of spectrum) High frequencies = edges, noise (edges of spectrum)
  • Ideal Low-Pass Filter (ILPF): Allows all frequencies below cutoff D₀ — sharp boundary. Causes ringing artifacts (Gibbs effect).
  • Butterworth LPF (BLPF): Smooth transition around cutoff. Order n controls transition sharpness. No ringing. Most practical.
  • Gaussian LPF (GLPF): Gaussian-shaped transfer function. No ringing. Smooth results. Best for noise removal.
  • Ideal High-Pass Filter (IHPF): Allows frequencies above D₀ — edge enhancement. Also causes ringing.
  • Homomorphic Filter: Simultaneously enhances edges (illumination correction) and compresses dynamic range. Useful for non-uniform lighting images.

Spatial domain = direct convolution with mask. Frequency domain = FFT → filter → IFFT. Key filters to memorize: Averaging (noise removal), Median (salt-pepper noise), Sobel (edges), Gaussian LPF (smooth), Butterworth (practical LPF). ✏️ Image filtering is fundamental to image processing — spatial domain filters provide simplicity and speed for small kernels, while frequency domain filters offer powerful global operations for complex enhancement tasks like periodic noise removal and illumination correction.

Morphological Image Processing — Definition

Morphological Image Processing is a collection of non-linear operations that process images based on shape and structure. It uses a small binary shape called a Structuring Element (SE) to probe and interact with the input image.

Key Terms: A = Input image (binary/grayscale). B = Structuring Element (SE) — the probe shape. Operations modify the shape of foreground objects in A based on SE B.
1. Dilation (A ⊕ B)

Dilation expands / grows the foreground (white) objects in the image. The SE is placed at each pixel; if any pixel under SE overlaps the foreground — output pixel is set to 1 (foreground).

A ⊕ B = { z | (B̂)z ∩ A ≠ ∅ } → A pixel becomes 1 if any SE pixel touches foreground of A

Q6. Describe Thinning and Thickening operations. Provide an example where these operations are useful. Write a short note on Thinning. 🔥 POPULAR
5 Marks7 Marks
Thinning — Definition

Thinning is a morphological operation that iteratively removes boundary pixels from a binary object until only a 1-pixel-wide skeleton (medial axis) remains, while preserving connectivity and topology.

Thinning: A ⊗ B = A ∩ (A ⊖ B)ᶜ = A - (A ⊛ B) where B is a structuring element for boundary detection Iteratively applied until no more pixels can be removed
  • Reduces objects to their skeleton/medial axis.
  • The skeleton has the same connectivity as the original object.
  • Pixels are removed if their removal doesn't disconnect the object (using hit-or-miss criterion).
  • Applications:
    • OCR (Optical Character Recognition) — reduce text to skeleton for recognition.
    • Fingerprint analysis — extract ridge skeleton for matching.
    • Medical imaging — skeleton of blood vessels, neurons, bones.
    • Shape analysis — compact representation for shape matching.
Thickening — Definition

Thickening is the dual operation of thinning — it adds pixels to the boundary of objects, growing the skeleton outward. Defined as the complement of thinning applied to the complement image.

Thickening: A ⊙ B = A ∪ (A ⊛ B) → Pixels are ADDED to the boundary (opposite of thinning)
  • Creates thicker versions of skeleton structures.
  • Used when objects are too thin and need to be made broader.
  • Application: Enhancing thin lines in engineering drawings before printing.
  • Creating broader zones around skeletal paths for navigation planning in robotics.
⭐

Short note on Thinning: Definition → formula → properties (preserves connectivity) → 3 applications (OCR, fingerprint, blood vessel) → conclusion. This is a perfect 5-mark answer. Always mention that thinning = skeleton extraction.

✏️ Thinning is a critical preprocessing step in pattern recognition — it reduces complex shapes to simple 1-pixel skeletons while preserving shape topology, enabling efficient shape analysis and recognition in fingerprint matching, OCR, and medical image analysis.

Recognition Methodology — Overview

Image recognition follows a structured pipeline of steps that transform raw pixel data into meaningful labels and decisions.

Image Recognition Pipeline
Raw Image (Pixels)

⬇

⬇

  • 1. Conditioning: Pre-processing to improve image quality — noise removal (Gaussian/Median filter), contrast enhancement (histogram equalization), geometric correction (removing distortion).
  • 2. Labeling: Assigning labels (class tags) to image regions or features. Connected component labeling assigns unique IDs to connected foreground regions. Edge labeling identifies boundary types.
  • 3. Grouping: Combining pixels/regions into meaningful objects based on similarity — segmentation (thresholding, region growing, clustering). Groups pixels that belong to the same object.
  • 4. Extracting: Measuring properties of labeled regions — area, perimeter, centroid, moments, Fourier descriptors. Creates a feature vector for each object.
  • 5. Matching: Comparing extracted feature vectors against known templates/models to classify/recognize objects. Uses nearest-neighbor, SVM, CNN classifiers.

✏️ The recognition methodology provides a systematic five-step pipeline from raw image to object recognition — each step refining the information until meaningful recognition decisions can be made with confidence.

Q8. What is Image Segmentation? Discuss Thresholding and Connected Component Labeling techniques. 🔥 POPULAR
— OR —
Q8B. Explain global and adaptive thresholding techniques. What is Thresholding? Discuss its use and limitations.
5 Marks7 Marks10 Marks
Image Segmentation — Definition

Image Segmentation is the process of partitioning a digital image into multiple segments (regions or objects) to simplify its representation and make analysis more meaningful. It separates the image into foreground and background or into different object regions.

1. Thresholding

Thresholding converts a grayscale image into a binary image by comparing each pixel intensity with a threshold value T.

g(x,y) = 1 (White/Foreground) if f(x,y) ≥ T = 0 (Black/Background) if f(x,y) < T
Types of Thresholding
  • Global Thresholding: One single threshold T applied to the entire image. Works well for uniform lighting. T can be found using histogram analysis (valley between peaks). Otsu's Method: Automatically finds optimal T by maximizing inter-class variance.
  • Adaptive Thresholding (Local Thresholding): Different threshold T(x,y) computed for each region/pixel based on local neighborhood. Handles non-uniform illumination. Types: Mean-based, Gaussian-based, Bernsen method.
  • Multi-level Thresholding: Uses multiple thresholds T₁, T₂, ... to segment image into more than 2 classes.
Limitations of Thresholding
  • Does NOT use spatial relationships between pixels — ignores context.
  • Fails for images with non-uniform illumination (unless adaptive).
  • Sensitive to noise — noise pixels get misclassified.
  • Cannot separate objects of similar intensity but different spatial locations.
  • Binary output — loses all intensity information.
2. Connected Component Labeling (CCL)

CCL is an algorithm that identifies and labels each separate connected group of foreground pixels with a unique integer label after thresholding.

  • 4-connectivity: A pixel is connected to its 4 neighbors (up, down, left, right).
  • 8-connectivity: A pixel is connected to all 8 neighbors (including diagonals).
  • Two-pass Algorithm:
    • Pass 1: Scan left-to-right, top-to-bottom. Assign provisional labels. Record equivalences (if two labels are actually the same component).
    • Pass 2: Replace provisional labels with final minimum equivalent labels.
  • Applications: Counting objects (blood cells, coins), isolating objects for further analysis, blob detection.
⭐

Thresholding formula must be written. Otsu's method = automatic optimal threshold using histogram — mention it for extra marks. CCL = two-pass algorithm. 4-vs-8 connectivity is a common MCQ. Limitations of thresholding = fail with non-uniform illumination (→ use adaptive thresholding as solution).

✏️ Thresholding is the simplest and fastest segmentation technique, ideal for images with clear bimodal histograms. Connected component labeling then isolates individual objects for further analysis, making the (Threshold + CCL) pipeline fundamental to binary machine vision.

Q9. What are Boundary and Region Descriptors? Explain their importance in image analysis. Explain Boundary Descriptors in detail with a neat diagram. 🔥 POPULAR
5 Marks7 Marks10 Marks
Descriptors — Introduction

After segmentation, Descriptors are numerical features that represent the properties of a segmented region or boundary for subsequent classification and recognition tasks. They convert visual shapes into compact numerical vectors.

A. Boundary Descriptors

Describe the shape of the boundary/contour of an object. Used when shape is the key feature.

  • Chain Code: Represents boundary as a sequence of directional codes (0–7 for 8-connectivity). Start at a boundary pixel and record direction to next boundary pixel. Chain: 0=right, 1=upper-right, 2=up, 3=upper-left, 4=left, 5=lower-left, 6=down, 7=lower-right.
  • Polygonal Approximation: Approximate boundary with a polygon (fewer vertices). Reduces data while maintaining shape. Min-perimeter polygon method.
  • Boundary Signatures: Plot of distance r(θ) from centroid to boundary as a function of angle θ. 1D representation of 2D boundary — easy to analyze using Fourier transform.
  • Fourier Descriptors: Apply Fourier Transform to boundary coordinates (x+jy). Low-frequency coefficients describe overall shape; high-frequency describe fine details. Scale, rotation, translation invariant.
  • Shape Numbers: Derived from chain code — first difference of chain code, then take minimum rotation. Rotation-invariant boundary descriptor.
B. Region Descriptors

Describe the properties of the interior (region) of the object. Used for area-based analysis.

  • Area: Number of pixels in the region. Simple but important measure.
  • Perimeter: Number of boundary pixels. Used to compute circularity = 4π×Area/Perimeter².
  • Compactness/Circularity: Ratio of area to perimeter² — measures how "round" an object is. Circle = 1, elongated = lower value.
  • Euler Number: E = C - H (C = connected components, H = holes). Topological descriptor.
  • Moments: Statistical measures of intensity distribution — zeroth moment=area, first moments=centroid, second moments=orientation/eccentricity.
  • Bounding Box: Smallest axis-aligned rectangle containing the region.
  • Eccentricity: Ratio of major to minor axis length of equivalent ellipse — distinguishes elongated from circular objects.

Hierarchical Segmentation — Split and Merge

The Split-and-Merge technique is a hierarchical image segmentation method that works on a quadtree representation of the image. It combines top-down splitting and bottom-up merging to find homogeneous regions.

Split and Merge — Quadtree
Whole Image R (non-homogeneous)
⬇ SPLIT into 4 quadrants
R₁ (homogeneous)
R₂ (split further)
R₃ (homogeneous)
R₄ (split further)
⬇ MERGE adjacent similar quadrants
Final Segmented Regions
Split Phase
  • Start with the entire image as a single region R.
  • If R is not homogeneous (predicate P(R) = FALSE), split it into 4 equal quadrants.
  • Repeat recursively for each non-homogeneous sub-region.
  • Homogeneity criterion: All pixels within the region have similar intensity (variance below threshold).
  • Continue until all regions are homogeneous OR minimum region size is reached.
Merge Phase
  • After splitting, examine adjacent regions Rᵢ and Rⱼ at the same quadtree level.
  • If P(Rᵢ ∪ Rⱼ) = TRUE (merged region is homogeneous), merge them into one region.
  • Continue until no further merging is possible.
  • Result: A set of non-overlapping, connected, homogeneous regions that cover the entire image.
Other Region-based Segmentation Techniques
  • Region Growing: Start from a seed pixel and grow the region by adding neighboring pixels that are similar (within a similarity criterion) to the seed. Good for simple, uniform regions.
  • Region Shrinking: Opposite of growing — start with the full image and shrink by removing boundary pixels that are dissimilar.
  • Watershed Segmentation: Treats image as topographic map (pixel intensity = elevation). Finds catchment basins and watershed lines. Excellent for separating touching objects.
  • K-Means Clustering (Spatial Clustering): Groups pixels into K clusters based on color/intensity similarity. Iterative algorithm — good for color image segmentation.

Curve Fitting — Least-Square Fitting

Least-Square Fitting is a mathematical method to find the best-fit curve (line, polynomial, circle) to a set of data points by minimizing the sum of squares of residuals (vertical distances between data points and the curve).

For line y = mx + c: Minimize: E = Σ(yᵢ - mxᵢ - c)² Solution: m = [nΣxᵢyᵢ - ΣxᵢΣyᵢ] / [nΣxᵢ² - (Σxᵢ)²] c = (Σyᵢ - mΣxᵢ) / n

Applications in CVIP: Line fitting in edge detection, fitting curves to boundary contours, fitting circles to circular features (Hough Transform uses least-squares implicitly), road lane detection.

Q12. What are the various Representation Schemes of digital image processing? Explain.

Representation Schemes

Representation Schemes define how to encode the boundary or interior of a segmented region efficiently for storage, analysis, and recognition.

Types of Representation Schemes
  • Chain Code: Encodes boundary as a sequence of directional codes. 4-connectivity (codes 0–3) or 8-connectivity (codes 0–7). Compact, but sensitive to noise. First difference = rotation-invariant version.
  • Polygonal Approximation: Represents boundary as a sequence of straight line segments (polygon). Reduces boundary data. Min-perimeter polygon or split-and-merge approach.
  • Quadtree Representation: Hierarchical partitioning of image into quadrants. Black nodes = all foreground, White nodes = all background, Gray nodes = mixed (subdivided). Efficient for regions with large uniform areas.
  • Medial Axis Transform (MAT/Skeleton): Represents region as its skeleton (medial axis) — set of center points of maximum inscribed circles. Captures shape topology compactly.
  • Run-Length Encoding (RLE): Encodes rows of pixels as (value, run-length) pairs. Very efficient for binary images with large uniform regions. Used in fax machines, JPEG.
  • Boundary Code (B-rep): Explicit list of boundary pixel coordinates. Simple, but requires much storage for complex boundaries.
⭐

Remember at least 4 schemes: Chain Code, Polygonal Approx, Quadtree, Run-Length Encoding (RLE). Draw the quadtree subdivision diagram. Chain code = boundary encoding, Quadtree = region encoding, RLE = compression-based encoding.

✏️ Different representation schemes offer different trade-offs between compactness, robustness, and ease of analysis — chain codes for boundary analysis, quadtrees for region analysis, and RLE for efficient storage.

Region Analysis involves quantitatively measuring properties of connected image regions to describe their size, shape, position, and content — producing feature vectors for object recognition and classification.

Moments are weighted averages of pixel intensities used to compute geometric properties of a region. They capture shape information compactly.

For grayscale images, moments incorporate pixel intensity values:

Gray-level moment: m_pq = ΣΣ x^p · y^q · f(x,y) where f(x,y) = gray intensity at (x,y) (not just 0/1) → Captures both spatial distribution AND intensity distribution of the region
  • Provides richer description than binary moments.

Boundary Analysis is the study and measurement of an object's contour/boundary to characterize its shape. The boundary contains significant shape information and is computationally more efficient than analyzing the full region.

  • Advantage over 3D model matching: No 3D model needed — works purely from 2D example images.
  • Application: Robot grasping (identify part AND its orientation), vehicle recognition from cameras.

Matching Frameworks — Introduction

Image Matching is the process of determining whether two image descriptions represent the same object or scene. Different frameworks use different representations and matching strategies.

1. Distance Relational Approach

In this approach, objects are described by a set of features and the distances (relations) between them. Matching compares the relational distance structure of the input to stored models.

  • Object description: Set of features {f₁, f₂, ..., fₙ} + distance matrix D[i][j] = distance between features i and j.
  • Matching: Find a correspondence between input features and model features such that distances are preserved (isomorphic subgraph matching).
  • Flexibility: Can handle partial matches (some features missing) using relaxation labeling.
  • Example: Matching faces — features are eye, nose, mouth positions. Distances between them must match the model's distance matrix.
  • Advantage: Robust to small shape changes, handles partial occlusion, translation invariant (distances are translation-invariant).
Distance Measures in Image Processing
Euclidean Distance: d_E(p,q) = √((x₁-x₂)² + (y₁-y₂)²) → Real geometric distance between pixels p and q City-Block (Manhattan) Distance: d₄(p,q) = |x₁-x₂| + |y₁-y₂| → Only horizontal/vertical movement Chessboard Distance: d₈(p,q) = max(|x₁-x₂|, |y₁-y₂|) → Diagonal movement also counted
2. Ordered Structural Matching

In Ordered Structural Matching, objects are described as ordered sequences of parts or features. Matching uses string-matching or Dynamic Programming algorithms.

  • Object = ordered sequence of primitive elements (edges, curves, corners).
  • Matching: Compute edit distance (Levenshtein distance) between sequences or use Dynamic Time Warping (DTW).
  • Best for: Objects with natural ordering — handwriting (characters as sequence of strokes), contours (sequence of curve segments).
  • Dynamic Programming gives efficient O(nm) matching algorithm.

Consistency Labeling — Introduction

Consistency Labeling is a problem in computer vision where each image primitive (region, edge, vertex) must be assigned a label from a set of possible labels such that the assignment is globally consistent — i.e., neighboring labels are compatible.

Classic Example: Line labeling in a line drawing interpretation — each line segment must be labeled as either a convex edge (+), concave edge (−), or occluding boundary (→) such that all labels at each junction are physically possible for a 3D object.
Backtracking Algorithm

Backtracking is a systematic, depth-first search algorithm that tries all possible label assignments for image primitives, abandoning (backtracking) any partial assignment that becomes inconsistent — pruning the search space.

Backtracking Algorithm Steps
Backtracking Search Tree
Start: Assign label L₁ to primitive u₁
⬇ Check consistency with neighbors
Consistent → Proceed to u₂
Inconsistent → BACKTRACK
⬇
Try next label for u₁
⬇
Continue until all primitives labeled OR all options exhausted
Algorithm: procedure BACKTRACK(level k): for each label Lᵢ in label set L: assign Lᵢ to primitive uₖ if consistent(uₖ, Lᵢ, already-labeled neighbors): if k == N (all primitives labeled): SOLUTION FOUND — output labels else: BACKTRACK(k+1) // recurse deeper // else: try next label (implicit backtrack) Consistency check: label(uₖ) must be compatible with labels already assigned to uₖ's neighbors
Example: Line Labeling (Waltz Algorithm)
  • Image primitives: Line segments at junctions of a polyhedron drawing.
  • Labels: + (convex), − (concave), → or ← (occluding boundary).
  • Constraint: At each junction, only certain label combinations are physically realizable (from a catalog of valid junction types).
  • Backtracking: Start with one line, assign a label, propagate constraints to adjacent lines. If contradiction found → backtrack and try different label.
  • Waltz filtering: Constraint propagation prunes label sets before backtracking — dramatically reduces search space.
Properties of Backtracking
  • Complete: Finds all solutions or proves none exists.
  • Correct: Only outputs consistent labelings.
  • Exponential worst case: O(|L|ᴺ) — but pruning greatly reduces practical complexity.
  • Improvement: Forward checking + constraint propagation (arc consistency) makes it practical.

Facet Model — Definition

The Facet Model represents an image surface as a piecewise polynomial (facet) surface — each small local region is fitted with a polynomial (usually bivariate cubic) to model the local intensity landscape. It enables accurate feature extraction at the local level.

  • Image intensity surface approximated by: f(x,y) ≈ k₁ + k₂x + k₃y + k₄x² + k₅xy + k₆y² + ... (polynomial)
  • Coefficients fitted using Least-Squares for each local window.
  • From coefficients: Compute gradient, curvature, Laplacian analytically — no numerical differentiation needed.
  • Facet-based edge detection: Find locations where gradient magnitude exceeds threshold AND Laplacian zero crossing exists → subpixel accurate edge detection.
  • Facet-based peak detection: Find local maxima of intensity surface → detect bright spots, blobs.
  • Shape Classification: Classify local surface shape (pit, flat, ridge, saddle, peak) based on gradient and curvature — like terrain classification.
Importance of Shape Recognition
  • Object Identification: Recognize objects regardless of color or texture — shape is invariant to lighting.
  • Industrial Inspection: Detect manufacturing defects by comparing shape to CAD model.
  • Medical Diagnosis: Identify tumors, organs, blood cells by shape analysis.
  • Robotics: Robots grasp objects by understanding their 3D shape.
  • Autonomous Driving: Recognize pedestrians, signs, vehicles by shape.
  • Biometrics: Fingerprint, iris, face recognition — all shape-based.
Evaluating Shape Descriptors in 3D Vision
  • Invariance: Descriptor should be invariant to rotation, scale, translation (RST). Test by applying transforms and checking descriptor stability.
  • Discriminability: Different shapes should have different descriptors. Measured by classification rate on benchmark datasets.
  • Robustness: Robust to noise, occlusion, partial views. Test with noisy and occluded versions of test shapes.
  • Compactness: Descriptor vector should be short (small number of dimensions) for efficiency.
  • Computational efficiency: Fast to compute for real-time applications.
⭐

Facet model = fit local polynomial to image intensity → analytically compute gradients. Key advantage: subpixel edge accuracy. Shape recognition importance: 3-5 applications always needed. Shape descriptor evaluation criteria: Invariance + Discriminability + Robustness.

✏️ The facet model provides a mathematically elegant local image description enabling accurate, continuous-domain feature extraction. Shape recognition, powered by invariant descriptors, is the cornerstone of intelligent visual systems from industrial inspection to autonomous driving.

Q19. What is image intensity in image processing? Discuss Intensity Matching of 1D signals.

Image Intensity

Image Intensity (or gray level) is the numerical value assigned to each pixel representing its brightness. For grayscale images: 0 = black, 255 = white. For color: (R,G,B) triple. Intensity represents the amount of light reflected/emitted at each pixel position.

Intensity Matching of 1D Signals

For matching image regions, intensity profiles (rows/columns of pixel values) are treated as 1D signals and matched using signal correlation.

Cross-Correlation (Template Matching in 1D): NCC(d) = Σ [f(x) · t(x-d)] / √(Σf²(x) · Σt²(x)) where: f(x) = image signal (1D intensity profile) t(x) = template signal d = displacement (shift) Peak of NCC at displacement d* = best match location NCC ∈ [-1, +1] (1 = perfect match, 0 = no correlation, -1 = inverse)
  • 1D matching used in stereo vision — match row-scanlines of left and right camera images to find disparity.
  • Sum of Squared Differences (SSD) is simpler alternative: SSD(d) = Σ[f(x) - t(x-d)]² → minimum = best match.
  • Application: Stereo depth estimation, barcode reading, 1D signal alignment in medical signals.

✏️ Intensity matching using cross-correlation provides a robust method for finding corresponding regions between images, forming the foundation of stereo vision and template-based object detection.

The Hough Transform is a feature extraction technique that detects instances of geometric shapes (lines, circles, ellipses) by finding peaks in a parameter space (accumulator array). It is robust to noise and partial occlusion.

Hough Transform for Circles
Circle equation: (x - a)² + (y - b)² = r² Parameters: center (a, b) and radius r For each edge pixel (x,y) and each possible radius r: → compute (a, b): a = x - r·cosθ, b = y - r·sinθ → vote in 3D accumulator A[a][b][r] Peak at (a*, b*, r*) in accumulator = detected circle with center (a*, b*) and radius r* Accurate centre: (a*, b*) = position of peak in Hough space Sub-pixel accuracy: Fit parabola to accumulator peak neighbourhood
Hough Transform for Lines (Full Derivation)
Normal (Hesse) form of line: ρ = x·cosθ + y·sinθ For edge pixel (x₀, y₀): ρ(θ) = x₀·cosθ + y₀·sinθ for θ ∈ [0°, 180°] → This is a sinusoid in (ρ,θ) space For TWO collinear edge pixels (x₀,y₀) and (x₁,y₁): Their sinusoids intersect at (ρ*, θ*) = parameters of line through both Peak detection: Find (ρ*, θ*) where accumulator A[ρ,θ] is maximum
Object Detection Using Hough Transform
  • Line detection: 2D accumulator (ρ, θ). Used for: lane detection, document deskewing, barcode detection.
  • Circle detection: 3D accumulator (a, b, r). Used for: eye detection (iris), coin detection, bubble detection in microscopy.
  • Ellipse detection: 5D accumulator (a, b, θ, major, minor). Computationally expensive.
  • Generalized Hough Transform (GHT): Detects arbitrary shapes by storing reference table of edge directions vs displacement vectors to shape centroid. Used for arbitrary template matching.
Accurate Centre Location

To improve accuracy of detected circle centre beyond the discrete accumulator resolution:

  • Fit a 2D Gaussian or paraboloid to the peak neighbourhood in the accumulator → sub-pixel centre accuracy.
  • Alternatively: Use the peak as initial estimate → refine using gradient descent on edge-to-circle distance.
  • Least-squares fit of circle equation to detected edge points → optimal (a, b, r) with sub-pixel precision.

✏️ The Hough Transform elegantly converts global shape detection into a local peak-finding problem — its ability to detect shapes despite noise, gaps, and partial occlusion makes it one of the most robust and widely-used techniques in classical computer vision.

PCA — Definition

Principal Component Analysis (PCA) is a dimensionality reduction technique that transforms a high-dimensional dataset into a lower-dimensional space by finding the directions (principal components) of maximum variance in the data.

Eigenfaces: PCA applied to face images — each face image (50×50=2500 pixels) is a vector in 2500-dimensional space. PCA finds the principal components of this space → "Eigenfaces" → project each face onto top-K eigenfaces for compact recognition.
PCA Algorithm (Step-by-Step)
Step 1: Data preparation X = matrix of N training images, each row = flattened image vector Step 2: Mean centering μ = (1/N) ΣXᵢ (mean image) X' = X - μ (subtract mean from each image) Step 3: Covariance matrix C = (1/N) X'ᵀ X' (covariance of centered data) Step 4: Eigendecomposition Find eigenvalues λ₁ ≥ λ₂ ≥ ... ≥ λₙ and eigenvectors e₁, e₂, ..., eₙ of C Step 5: Select top-K eigenvectors (Principal Components) PC matrix W = [e₁, e₂, ..., eK] (K << N) Step 6: Project data Feature vector = Wᵀ(x - μ) (K-dimensional feature vector) Step 7: Recognition Compare input feature vector to stored feature vectors (nearest neighbour)
Properties of PCA
  • Each principal component is orthogonal to all others.
  • First PC has maximum variance, each subsequent PC has maximum remaining variance.
  • Data compression: Represent N-dimensional data with K dimensions (K ≪ N).
  • Reconstruction: Approximate original image from K-dimensional feature vector.
  • Limitations: Linear method only — cannot capture non-linear variations. Eigenfaces sensitive to lighting and pose changes.
Feature Extraction — Overview

Feature Extraction transforms raw image data into compact, discriminative representations (feature vectors) suitable for classification.

  • HOG (Histogram of Oriented Gradients): Computes gradient orientation histograms in local cells. Excellent for pedestrian detection. Used in classic SVM-HOG person detector.
  • SIFT (Scale-Invariant Feature Transform): Detects keypoints at multiple scales → computes 128-dim descriptor. Invariant to scale, rotation, illumination changes.
  • LBP (Local Binary Pattern): Encodes local texture by comparing pixel with neighbors → binary pattern. Lightweight, rotation-invariant. Used in face recognition.
  • CNN Features: Deep CNN layers automatically learn hierarchical features from raw pixels. Best discriminative features for most visual tasks.
  • Gabor Filters: Band-pass filters at multiple orientations → good for texture feature extraction.
  • Zernike Moments: Orthogonal polynomial-based moments → rotation-invariant region features, better than Hu's moments for complex shapes.

Neural Networks for Pattern Recognition — Introduction

Neural Networks are computational models inspired by biological neural networks (brain) that learn to recognize patterns by adjusting connection weights through training on labeled examples.

How CNN Components Work
  • Convolutional Layer: Applies learned filters to detect local features — edges, textures, shapes. Each filter detects one specific pattern. Result = feature map.
  • ReLU Activation: max(0, x) — introduces non-linearity. Allows network to learn complex decision boundaries.
  • Pooling Layer (Max/Avg): Reduces spatial dimensions. Provides translation invariance — feature detected even if slightly shifted.
  • Fully Connected Layer: Combines all features to make final classification decision. Like a traditional neural network on extracted features.
  • Softmax Output: Converts raw scores to probability distribution over all classes.
  • Backpropagation + SGD: Training algorithm — computes gradient of loss, updates weights to minimize classification error.
CNN for Shape Recognition
  • Early layers: Learn low-level features — edges, corners, blobs (shape primitives).
  • Middle layers: Learn mid-level features — textures, parts (e.g., wheels, eyes).
  • Deep layers: Learn high-level semantic features — whole objects, object categories.
  • Famous Architectures for Shape Recognition:
    • LeNet-5 (1998): First CNN for digit recognition (MNIST dataset).
    • AlexNet (2012): Won ImageNet. Deep CNN with ReLU, Dropout, GPU training.
    • VGGNet (2014): 16-19 layers, uniform 3×3 conv filters.
    • ResNet (2015): 152 layers with residual connections (skip connections) — solves vanishing gradient.
    • YOLO (2016): Real-time object detection — detects shape+location simultaneously.
Training Process for Shape Recognition
Training: 1. Forward pass: input image → CNN → predicted class 2. Compute loss: L = -log(p_correct_class) [cross-entropy loss] 3. Backward pass: ΔW = -η × ∂L/∂W [gradient descent] 4. Repeat for all training images until loss converges Testing: New image → CNN → argmax(softmax output) → predicted shape label
